# 공부 기록

Unity 6000.4.5f1에서 통합 프로젝트를 열거나 Mac용 공부 기록 실행본을 사용합니다. 로그인 후 좌석 가까이에서 **E**를 누르면 우측 하단에 카메라 미리보기와 **시작**, **일어나기** 버튼이 표시됩니다. **시작** 또는 **F8**을 누르면 분석을 시작합니다. **이번 공부**와 **오늘 누적**은 화면 상단 중앙에 표시됩니다. 판정 상태는 3인칭에서 캐릭터 머리 위, 1인칭에서는 시간 아래에 표시됩니다. 다른 창으로 이동해도 측정은 이어집니다. 로비 **MY** 또는 **F9**에서 최근 세션과 행동별 시간을 확인할 수 있습니다. **일어나기**로 측정을 끝냅니다.

컴퓨터로 공부할 때는 시작 후 **공부 창 선택**에서 교재나 강의를 띄운 창을 고른 뒤 해당 창으로 이동합니다. macOS에서는 처음에 화면 기록 권한이 필요합니다. 선택한 창의 제목을 확인하고, 제목만으로 판정하기 어려우면 그 창을 약 3초 간격으로 확인합니다. 화면 내용은 로컬에서 분석합니다. 창이나 탭이 바뀌면 이전 화면 판정을 버립니다. 종이 읽기·필기는 카메라 근거를 사용하고 화면 사용 중 자료를 확인할 수 없으면 상태를 **화면 확인 필요**로 표시하고 집계를 보류합니다.

웹캠과 화면에서 얻은 근거를 합친 점수를 최근 3초 동안 종합합니다. 공부 시작에는 3초, 비공부 전환에는 2초, 자는중 표시에는 8초 동안의 근거가 필요합니다. 공부 시간은 유효한 촬영 시각 사이의 경과 시간으로 계산합니다. 비공부 후보가 생기면 전환을 확인하는 동안 그 시간의 합산을 기다립니다. 단발 오판이 취소되면 보류한 시간이 합산됩니다. 모델 준비, 화면 확인 보류, 유효한 사진을 받지 못한 구간은 집계에서 제외합니다.

일별 합계는 한국시간 자정을 기준으로 계산합니다. 영상은 기기에서 분석하고, 계정에는 세션과 행동별 시간 구간만 저장합니다. 기기에 기록을 보관하면서 약 30초마다, 그리고 측정 종료 후에 동기화합니다. 연결이 끊기면 같은 계정으로 다시 연결할 때 재전송합니다. 다른 기기의 최신 합계는 기록 창을 열거나 **동기화**를 눌러 확인할 수 있습니다. 서버에 이미 저장된 시간과 겹쳐 거절된 기록은 기기에 보관합니다. 이후의 정상 세션은 계속 동기화됩니다.

## 개발 및 배포

같은 컴퓨터에서 서로 다른 계정으로 게임 두 창을 열면 각자 공부 기록을 시작할 수 있습니다. 로그인한 계정마다 별도 파일에 저장하고 로그아웃하면 해당 파일의 잠금을 풉니다. 기존 공용 파일의 미전송 구간과 일별 합계는 그 계정이 처음 로그인할 때 승계합니다. 이전 버전 게임이 기존 파일을 사용하고 있으면 해당 창을 닫은 뒤 새 게임이 자동으로 다시 시도합니다.

공부 기록 변경은 PR #25에 있습니다. 선행 통합 PR #23을 기반으로 합니다. Supabase migration `20261112071053_study_records.sql`을 적용한 뒤 `study` Edge Function을 배포합니다. 함수는 기존 계정 인증과 같은 방식으로 Auth에서 로그인 토큰을 검증하고 서버 권한으로 저장합니다. Unity는 `AccountSession.StudyCallAsync`로 호출합니다. 계정 UUID는 서버가 인증한 사용자를 기준으로 결정합니다.

`public.study_sessions`와 `public.study_segments`는 본인 조회 RLS를 사용합니다. 세션 ID와 구간 번호가 같은 재전송은 한 번만 반영합니다. 서버는 입력 범위, 순서, 다른 세션과의 겹침을 확인합니다. `study_summary`는 오늘 공부 합계와 최근 20개 세션을 반환합니다. 이번 기록은 개인 통계용이며 기존 레벨이나 보상 계산의 입력으로 사용하지 않습니다.

Mac용 로컬 빌드는 `Builds/CampusCommons-study-macos-arm64/CampusCommons.app`에 있습니다. 이 브랜치에서 기존 데스크톱 빌드 명령을 실행해도 공부 기록 기능이 포함됩니다.
