# CC-34 로비 계정 메뉴와 HUD

- 담당 HIGHCHOI. Issue #34, Draft PR #35, 브랜치 `fix/cc-34-lobby-menu`. 시작 기준 `origin/main` `4b48b9c`.
- 기존 계정과 공부 기록의 두 패널이 우측 상단의 같은 영역에서 겹쳤습니다. 이제 닉네임과 레벨은 첫 줄, 오늘 공부와 기록 버튼은 둘째 줄에 표시됩니다. 인벤토리와 외형 설정이 열려 있으면 해당 패널을 우선합니다.
- 로비에서 Esc를 누르면 계속하기와 로그아웃을 선택할 수 있습니다. 로그아웃은 기존 인증 해제 경로를 사용하고 이메일과 비밀번호 입력 화면으로 이동합니다. 인벤토리·외형 설정·공부 기록이 열려 있으면 Esc를 먼저 처리합니다.
- 공유 변경은 `Assets/GrandLibrary/Scripts/Player.cs`의 이동·시점·인벤토리 입력 조건입니다. `AccountGate.LobbyMenuOwnsInput`은 Player와 공부 패널의 입력 소비자가 읽습니다. 메뉴 표시 중 이미 시작한 공부 분석은 이어집니다. 작업 전 열린 PR #31과 #33의 파일 범위를 확인했습니다. 공간과 캐릭터 담당자의 검토 접점은 해당 조건입니다. 추가 수정 점유 없음.
- Unity 6000.4.5f1 Play Mode에서 실제 GrandLibrary_Living 씬으로 회귀를 재현하고 수정 후 검사를 통과했습니다. 같은 검사에서 로비에만 메뉴가 열리고, 인벤토리·외형 설정·기록의 Esc 우선 처리, 1인칭 커서, 메뉴 닫기, 인증 해제와 로그인 화면 전환을 확인했습니다. 기본 아바타와 이 Mac의 선택 Sunbox 구성 모두 통과했습니다.
- 기존 계정, 인벤토리, 실제 씬 퀴즈·웹캠 연동, 좌석 정리 검사 통과. 인증과 퀴즈 설정은 테스트 입력을 사용했으며 개인 카메라를 실행하지 않았습니다. 기존 Unity SearchDatabase 초기화 예외는 변경 전후 같은 위치에서 발생했습니다.
