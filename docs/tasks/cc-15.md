- 구현: 탈출방 전용 스태미나, 세 칸 인벤토리와 동전 표시. 무작위 동전·자물쇠·공결증, 동전 1개로 캔음료 구매, 10초간 이동속도 증가. E/클릭 상호작용 및 1~3번 아이템 사용.
- 문: 탈출용 엘리베이터를 제외한 학교 문에 자물쇠를 쓰면 15초 동안 양쪽 자물쇠 표시와 물리 차단, 플레이어·몬스터·NPC의 문 열기 금지. 종료/시간 경과 시 해제.
- 교수: 빠르게 순회하다 가까운 플레이어에게 접근해 코딩 객관식 질문. 정답은 즉시 해제, 오답은 10초 복습, 공결증 사용 시 즉시 해제. 벽 너머에서는 감지하지 않음. 질문과 복습 중 멈추고 종료 후 지나가며 20초 재접촉 면제.
- 시설관리: 순회하며 주기적으로 노랑·검정 임시 벽 설치. 경로망으로 남은 문제지와 적어도 하나의 출구까지의 우회 가능성을 확인하며, 안전한 위치가 아니면 잠시 뒤 재시도. 벽은 20~30초 후 제거.
- 까마귀: 시작 시 플레이어 앞에 보이되 움직이지 않고 충돌은 비활성화. 첫 기존 문제 오답 시 기존 CrowAlert를 2D 경고음으로 재생하며 플레이어 위치를 향해 추격 시작. 이후 문/가림벽에 막힌 경로는 재탐색. 공포 이미지·NPC 및 아이템 그림은 사용자 확인 디자인.
- 공유 씬: 공간·씬 담당자 ghwls9896의 요청으로 GrandLibrary_Living.unity의 탈출 시작 지점과 방향만 Unity 에디터에서 변경. 디지털관 101호 맞은편 빈 엘리베이터 공간 (500, 0.08, 46), 남쪽을 향함. 작업 전 별도 백업했고 다른 열린 PR #4/#9/#10에는 같은 씬 변경이 없음을 확인. 프리팹/Player/GameStart/Packages 변경 없음.
- 변경 경계: 위 씬, EscapeGame.cs, Door.cs, Monster.cs, 새 EscapeSystems 및 EscapeBarricade 모듈, Resources 하위 이미지와 .meta.
- Unity 6000.4.5f1 검증: EscapeWorldIntegrationVerification.Run은 로비 문 진입·기존 문제·첫 오답·동전·자판기·아이템·교수·10초 복습·공결증·양면 자물쇠/15초 해제·안전 벽·복귀 통과. EscapeWorldPatrolVerification.Run은 두 NPC 이동과 시설관리 벽 설치 및 남은 문제/출구 경로를 확인. EscapeMonsterVerification.Run은 오답 전 대기와 오답 후 목표/이동 확인. EscapeSpawnVerification.Run은 실제 로비 문을 통해 101호 빈 엘리베이터 공간으로 진입, 방향과 복도로 이동, 복귀를 확인. 씬 편집 전 캡슐 충돌 없음 및 기존 20개 문제지 위치·엘리베이터 세 곳까지의 경로를 별도 확인. 네 시험은 Unity -batchmode -nographics -projectPath <작업폴더> -executeMethod <메서드> 형식으로 재실행 가능.
- 이미지 확인: Unity Sprite Point 필터, 최대 128px, 투명 배경. 공결 글자를 육안 확인. 교수와 자판기의 실제 씬 카메라 출력 확인.
- 유의: 벽 안전성은 현재 SchoolGrid와 잠긴 문·임시 벽의 연결 관계 기준이며 사람의 장시간 실플레이 밸런스와 모든 랜덤 시드 검증은 남음. 기존 GameTest는 현재 씬에서 비활성화된 옛 진입 포털을 기대해 실패하므로 실제 로비 문 방식은 위 별도 테스트로 확인. Unity SearchDatabase 초기화 오류가 배치 로그에 있었고 게임 코드 예외와는 구분함. 배치 모드에서는 HUD 화면 캡처가 저장되지 않아 해상도별 HUD 시각 검증은 남음. 경고음 파일 존재/재생 호출은 확인했으나 청감 평가는 별도.

## 아이템 디자인
내장 imagegen으로 1990년대 학교 공포 게임풍의 투명 픽셀 스프라이트를 제작: 오래된 황동 자물쇠, 파란 캔음료, ‘공결’ 글자와 붉은 도장이 있는 종이. 인게임 임포트 크기를 최대 128px로 제한했습니다.

## 후속 수정 및 리뷰 인계

- 잠긴 문을 앞쪽 경로에서 실제로 가로지를 때만 경로를 무효화하여 다시 탐색합니다. 뒤나 옆의 문은 이동을 멈추게 하지 않습니다.
- 게임 종료/재시작 시 문, 잠금, 문제지, 인벤토리, 몬스터와 월드 상태를 초기화합니다.
- 자판기 세 대는 복도 벽 근처 고정 위치에 두고 제공된 금오공과대학교 로고를 사용합니다. 동전 세 개, 자물쇠와 공결증 각 한 개를 분산합니다. 문제지는 교실 다섯 곳과 책상이 없는 방 두 곳에만 배치하며 난이도별 3/5/7개입니다.
- 타임어택 시간은 교수 질문 및 복습 중에도 흐릅니다.
- Unity 6000.4.5f1 `EscapeLockedDoorVerification.Run`: 별도 합성 격자와 충돌체를 이용해 잠긴 문의 앞·뒤·옆 이동, 실제 몬스터 경로 재계획과 우회 이동 및 15초 해제 확인. 실제 학교 맵 전체 문에 우회로가 있다고 보장하지 않습니다.
- `EscapePlacementVerification.Run`: 네 판에서 세 자판기 고정 위치·구매, 방 후보와 도달 경로 확인. `EscapeRoundResetVerification.Run`: 잡힘·탈출·시간 종료 후 재시작 확인. 교수 질문·복습 중 타이머는 별도 Play Mode 시험에서 확인.
- 공유 씬은 기존 브랜치의 시작 위치 변경 외에 이 후속 작업으로 변경하지 않았으며, 원본 프로젝트의 미커밋 파일을 보존했습니다. 최종 사람 승인 및 통합은 HIGHCHOI 담당입니다.
