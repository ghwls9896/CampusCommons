# CC-21 인벤토리 통합 검토

- 원 기능: I키 30칸 인벤토리, 1~5 단축 슬롯, 캐릭터 미리보기.
- 통합 전 오류 재현: Player가 로그인/방 전환으로 비활성화돼도 인벤토리가 열려 있었고, Sunbox 활성 분기에는 PreviewTexture와 인벤토리 렌더 요청 연결이 없었습니다.
- 수정: 인벤토리를 로비의 활성 Player 및 모달이 없는 상태에서만 사용합니다. 열려 있는 동안 Player 이동/시점 입력을 멈추고 C/Escape로 닫습니다. 방 전환·비활성화 때 미리보기도 해제합니다. 탈출룸의 별도 3칸 인벤토리는 유지합니다.
- 생산자/소비자: LibraryInventoryUI → Player.CanUseInventory 및 OwnsInput → Player.Update 입력 소유권. LibraryInventoryUI → LibraryAvatarPreview.SetInventoryVisible/PreviewTexture. 기존 커스터마이징 미리보기도 같은 카메라를 유지합니다.
- 사용자 통합 요청에 따라 공유 Player 연결점을 최소 수정했습니다. #23의 QuizRoom.BlocksMovement 분기를 통합 시 함께 보존해야 합니다. 씬·프리팹은 수정하지 않았습니다.
- Unity 6000.4.5f1 macOS: 원 오류 RED 재현 후 InventoryIntegrationChecks.Run PASS. Sunbox 미설치 분기와 실제 로컬 Sunbox 설치 분기 모두 확인. 비활성/퀴즈/탈출/마피아 입력 차단, 단축 슬롯, 커스터마이징과 상호 배제, 인벤토리 전용 미리보기, 1인칭에서 모델 표시, 닫기 후 카메라 해제 및 C 메뉴 재사용을 검사했습니다.
- Sunbox 원본/파생 에셋과 테스트용 define 설정은 커밋하지 않습니다. 다른 PC의 에셋 설치와 실제 시각 품질/수동 조작은 별도 확인 대상입니다.
- 보조 코드 리뷰에서 추가 blocker 없음. HIGHCHOI 사람 승인과 최종 합본 검증 후 병합합니다.
