# 두 좌석 퀴즈룸 인계

HIGHCHOI가 기능 커밋 `e7858e5`에서 Unity 퀴즈룸을 두 좌석의 실제 착석, 대기, 개인 PDF 선택, 풀이 및 결과 화면과 연결했다. 내 캐릭터와 상대에게 같은 머리 위 닉네임·레벨을 그리는 선행 클라이언트는 #47의 `58d3f12`다. [이슈 #49](https://github.com/ghwls9896/CampusCommons/issues/49) · [PR #51](https://github.com/ghwls9896/CampusCommons/pull/51)

| 확인 환경 | 결과 |
|---|---|
| Unity 6000.4.5f1 에디터 두 개, 같은 도서관, 같은 로컬 FastAPI | 첫 착석 대기, 서로 다른 좌석·3쪽/4쪽 개인 PDF, Lv.2와 Lv.8에서 공통 Lv.5, 서로 다른 문제, 단답형 15초 초과 시 저장 답 채점, 두 창의 결과 30/30·3/3 및 15/30·1/3, 개인 해설, 기립·퇴실을 확인했다. 로그인·Gemini 응답은 테스트 데이터였다. |
| 같은 Unity 버전의 기존 검사 | QuizRoomTest.Run, IntegratedQuizFlowTest.Run, DistributionBuild.CheckConfigurationGate(6개) 통과. |
| 머리 위 표시 | Sunbox와 기본 아바타 모두 이름·레벨 갱신, 레벨 없는 이전 서버 호환, 카메라 밖 숨김 회귀 검사 통과. |
| Mac 실제 실행본 | Apple Silicon, macOS 15용 팩에 웹캠 런타임을 포함해 빌드·서명 확인. 두 실제 로그인 화면, 포트 충돌과 무인증 좌석 거부 확인. Windows 실기기와 웹캠 실카메라 확인은 남아 있다. |

공유 Player·씬·프리팹 변경은 없다. 기존 배포 훅은 2인 접속에 쓰이지 않는 단독 퀴즈 토큰을 요구하지 않도록 조정했다. ghwls9896가 선행 #47을 통합한 뒤 자식 브랜치에 최신 main을 병합하고 base를 main으로 조정한다. #50 서버 배포 뒤 일반 빌드로 두 기기 확인을 진행한다. [플레이·배포 설정](../multiplayer/QUIZ_PLAY.md)

## Mac 두 창 실행 방식 수정

새 실행본은 Gemini 키 입력 없이 실행된다. 경기 상태는 Mac에서 관리하고, 기존 Render 서비스가 출제·채점한다. Unity 6000.4.5f1 퀴즈룸 Play Mode 검사에서 보정 확인 전·기본 3단계·계정 레벨 적용의 세 표시를 확인했다. 운영 Render로 서로 다른 시험 PDF 두 개를 출제·채점해 양쪽 결과와 개별 해설을 확인했다(프로필은 테스트 응답). 계정 레벨을 지정하는 출제는 서버 PR #50 배포 뒤 지원한다.

## 2026-11-19 교실 동기화와 칠판

교실 입장 후 로비 WebSocket 연결을 유지해 같은 공간에 있는 참가자의 위치·이동·착석 자세·닉네임·레벨을 표시한다. 기존 칠판 앞면에 월드 공간 Canvas를 배치했다. 참가 방법, 두 자리 대기, 개인별 출제, 키보드 입력과 결과 복습은 그 칠판에 표시한다. 좌석 접근 시 E 안내를 띄우고 macOS·Windows 플레이어에서는 기본 PDF 선택기를 연다. 공유 씬·Player·서버 프로토콜 편집은 없으며 공유 파일 작업은 종료했다.

Unity 6000.4.5f1 도서관 씬의 두 클라이언트가 로컬 WebSocket으로 서로의 교실 위치를 확인했다. 서로 다른 의자와 PDF로 대기·착석·3문항·선택/텍스트 답안·시간 초과·양쪽 점수/개인 복습·퇴실을 통과했다. 이 경기는 인증과 AI를 테스트 응답으로 대체했다. 실제 씬의 칠판 렌더링을 캡처해 표면 앞 배치와 읽기 영역을 확인했다. 칠판 버튼 레이캐스트·긴 보기 줄바꿈·입력 포커스, 양 공간 이름표·착석 회귀 검사도 통과했다.

Mac arm64 실행본은 서명과 카메라 패키지 해시를 검증하고 Render 직접 연결용 A·B 로그인 화면을 열었다. macOS 기본 파일 창의 PDF 필터·취소를 확인했다. Windows 코드는 컴파일했으며 Windows 파일 선택 실기기와 실제 한글 IME 조합은 미검증이다. #50 서버는 기배포 상태다. #47 이후 #51의 사람 검토·통합은 ghwls9896 담당이다.
