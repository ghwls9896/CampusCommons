# 두 좌석 퀴즈 서버 인계

HIGHCHOI가 기능 커밋 `6786063`에서 두 인증 좌석, PDF별 출제, 동시 시작, 시간·정답률·개인 해설까지 연결했다. 인증된 레벨은 서버 #45의 `074433a`에서 받는다. [이슈 #48](https://github.com/ghwls9896/CampusCommons/issues/48) · [PR #50](https://github.com/ghwls9896/CampusCommons/pull/50)

Python 3.14.2의 전체 백엔드 검사 85개가 통과했다. 실제 Unity 6000.4.5f1 두 인스턴스와 로컬 FastAPI로 다른 PDF 두 개, 3단계, 자동 시간 종료, 양쪽 성적과 각자 해설을 확인했다. 계정·Gemini 응답은 테스트 데이터였다. 실제 Gemini로 이 경기를 끝까지 치르는 확인은 남아 있다. [통신·채점 규격](../multiplayer/QUIZ_DUEL.md)

공유 backend/app.py는 기존 1인 API와 로비 라우트를 보존하고 대결 라우트를 추가했다. 두 경로는 AI 예산과 처리 락을 공유한다. 추가 수정 중인 공유 파일은 없다. ghwls9896가 #45부터 검토·통합한다. 의존 PR을 squash 병합한 후에는 최신 main을 자식 브랜치에 병합하고 PR의 base를 main으로 바꾼 뒤 CI를 재확인한다. 배포 시 기존 Render 단일 워커와 동일 프로젝트의 계정·Gemini 환경 설정을 사용한다.
