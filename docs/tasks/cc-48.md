# 두 좌석 퀴즈 서버 인계

HIGHCHOI가 기능 커밋 `6786063`에서 두 인증 좌석, PDF별 출제, 동시 시작, 시간·정답률·개인 해설까지 연결했다. 인증된 레벨은 서버 #45의 `074433a`에서 받는다. [이슈 #48](https://github.com/ghwls9896/CampusCommons/issues/48) · [PR #50](https://github.com/ghwls9896/CampusCommons/pull/50)

Python 3.14.2의 전체 백엔드 검사 96개가 통과했다. 실제 Unity 6000.4.5f1 두 인스턴스와 로컬 FastAPI로 다른 PDF 두 개, 3단계, 자동 시간 종료, 양쪽 성적과 각자 해설을 확인했다. 이 Unity 검사에서는 계정·Gemini 응답을 테스트 데이터로 대체했다. [통신·채점 규격](../multiplayer/QUIZ_DUEL.md)

공유 backend/app.py는 기존 1인 API와 로비 라우트를 보존하고 대결 라우트를 추가했다. 두 경로는 AI 예산과 처리 락을 공유한다. 추가 수정 중인 공유 파일은 없다. ghwls9896가 #45부터 검토·통합한다. 의존 PR을 squash 병합한 후에는 최신 main을 자식 브랜치에 병합하고 PR의 base를 main으로 바꾼 뒤 CI를 재확인한다. 배포 시 기존 Render 단일 워커와 동일 프로젝트의 계정·Gemini 환경 설정을 사용한다. [로비 서버 PR](https://github.com/ghwls9896/CampusCommons/pull/45)

## Render 실제 출제·채점 확인

Mac용 좌석 서버가 운영 퀴즈 서비스로 요청을 전달하도록 수정했다. 로컬 Gemini 키 없이 테스트 계정 레벨 2와 8로 수문학·천문학 PDF(각 2쪽)를 제출했다. Render 출제 2회와 채점 2회 모두 HTTP 200을 받았고 각자 3문항과 근거 페이지, 두 참가자의 성적(각 20/30, 2/3 정답)을 확인했다. 인증 프로필만 테스트 응답을 사용했다. 당시 운영 응답에 목표 레벨 확인 필드가 없어 게임은 기본 3단계 난이도로 진행됐다.

## 2026-11-19 운영 배포 확인

HIGHCHOI가 기존 무료 Render 서비스 `campuscommons-quiz`에 #50의 `bea1d02`를 수동 배포했다. Render는 16:10 KST에 Live 상태가 됐다. 운영 서비스에는 Unity와 같은 Supabase 프로젝트의 공개 접속 설정을 등록했다. [배포 기록](https://dashboard.render.com/web/srv-dboo2lgu01pc73ft8n0g/deploys/dep-dbva0rbl550s73965ji0)

- 실제 Supabase 검증 계정 Lv.2와 Lv.9로 로그인했다. Render에서 첫 좌석은 대기했고 두 번째 계정이 앉은 뒤 각자 PDF를 제출했다. 양쪽 상태에 `target_level=6`, `difficulty_mode=account`가 표시됐다.
- 수문학 PDF 2쪽에서는 하천 유량과 강우 조건, 천문학 PDF 1쪽에서는 항성 광도와 거리 추정에 관한 문제가 나왔다. 두 참가자 모두 객관식·단답형·서술형을 한 문제씩 풀었고 각자 해설 3개의 근거 쪽수가 모두 선택 범위와 일치했다. 두 좌석에 같은 점수·정답률·풀이 시간이 반환됐다.
- Mac 배포본에 포함된 좌석 서버 모듈도 실제 로그인과 Render로 따로 검증했다. 각 출제 요청의 PDF 본문을 선택한 쪽 원문과 대조했다. 두 응답 모두 HTTP 200, 목표 레벨 6, 3문항을 반환했다. 두 검증 모두 검증용 PDF를 사용했다. 이번 배포 검증은 API를 통해 진행했다.
- Mac 경로에서 생성된 천문학 단답형 한 문항은 원문의 거리 단위 `parsec`을 ‘파스칼’로 표기했다. 올바른 표기는 ‘파섹(pc)’이다. 자료·레벨 연결과 별도로 문항 용어의 정확도는 보완 대상이다.

공유 파일 작업은 종료했다. GitHub에서는 ghwls9896의 #45, #50 순서 검토·통합이 남았다. Render의 자동 배포는 꺼져 있고 기존 연결 브랜치는 `codex/pdf-quiz-room`이다. 이 배포는 특정 커밋을 선택해 진행했다. [PR #50](https://github.com/ghwls9896/CampusCommons/pull/50)
