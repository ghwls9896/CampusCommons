# CC-58 외형 동기화 인계

HIGHCHOI가 #55의 운영 테스트에서 보고한 아바타 외형 동기화 문제를 처리했다. 로비의 이동·이름표 위에 별도 외형 메시지를 추가했다. 서버는 현재 몸체·피부·머리·의상과 색상을 접속 동안 보관한다. Unity는 자기 기기의 Sunbox 카탈로그에서 아이템을 선택해 로비와 퀴즈룸의 상대 아바타에 반영한다. [이슈 #58](https://github.com/ghwls9896/CampusCommons/issues/58) · [PR #59](https://github.com/ghwls9896/CampusCommons/pull/59) · [통신 규격](../multiplayer/LOBBY.md#외형-동기화)

백엔드 103개, 팀 도구 16개와 Unity 6000.4.5f1 Play Mode의 Sunbox 및 기본 아바타 검사를 통과했다. 두 Unity 클라이언트가 로컬 서버에서 각각 상대의 의상·색상 변경을 렌더러로 확인하고 퀴즈룸에 들어가도 같은 외형을 받았다. 로그인은 테스트 응답이었다. 실제 Windows와 운영 Render 검증은 미완료다.

공유 씬·Player·백엔드 진입점 편집은 없다. 작업 파일 편집은 종료했다. 최신 커밋과 검사는 PR에 기록한다. ghwls9896 리뷰·병합 후 새 서버 코드를 Render에 배포하고 팀원은 최신 `main`의 Unity 프로젝트를 사용한다.

2026-11-23 후속 변경으로 외형을 같은 계정에 자동 저장한다. 기존 인증 API의 `data.campus_avatar_v1`에 로비와 같은 외형 형식을 기록한다. 실패한 저장은 이 기기의 해당 계정에서만 다시 시도한다. Unity 6000.4.5f1의 Sunbox Play Mode에서 빠른 선택 합치기, 직후 로그아웃, 계정 격리, 머리·몸체·상의 복원과 재시도를 확인했다. 인증 서버 응답은 테스트로 주입했다. 새 DB 마이그레이션은 필요 없고 실제 계정 재로그인 확인이 남아 있다.
