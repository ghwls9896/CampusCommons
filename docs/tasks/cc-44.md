# CC-44 공용 로비 서버 인계

HIGHCHOI가 `codex/cc-44-shared-lobby`에서 1단계 서버를 구현했다. 기능 커밋은 `317caaa`이며 병합 대상은 `main`이다. [이슈 #44](https://github.com/ghwls9896/CampusCommons/issues/44) · [PR #45](https://github.com/ghwls9896/CampusCommons/pull/45)

## 서버에서 확인한 동작

기존 FastAPI의 `/v1/lobby/ws`에서 계정 함수로 확인한 사용자에게 공용 로비 슬롯을 배정한다. 입장·이동·퇴장이 발생하면 닉네임과 위치가 포함된 전체 명단을 보낸다. 계정마다 현재 연결 하나를 유지하며, 정원 8명에서 새 계정은 만원 안내를 받는다. [Unity 연동 규격과 서버 설정](../multiplayer/LOBBY.md)

| 검사 | 결과 |
|---|---|
| Python 3.14.2, `cd backend && python -m pytest -q` | 69개 통과. 기존 퀴즈 52개와 로비 17개. 기존 Starlette TestClient의 httpx 사용 중단 예정 경고 1개. |
| 실제 Uvicorn 0.54.0과 WebSocket 클라이언트 17.4 | 로컬 TCP에서 8명이 움직일 때 각 클라이언트에 최종 위치 8개가 일치했다. 9번째 입장 거부, 첫 입장자 퇴장, 빈자리 재사용, 기존 연결 교체, 인증 만료 후 정리를 확인했다. |
| 인증 연동 | Supabase 계정 함수만 HTTP 모의 응답으로 대체했다. 인증 헤더, 요청 주소·본문, 응답에서 가져온 닉네임과 계정 식별, 오류 분기를 확인했다. |
| `python -m unittest discover -s Tools/team/tests -q` | 16개 통과. |
