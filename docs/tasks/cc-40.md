# CC-40 마피아룸 대화 인계

- 담당 HIGHCHOI. 작업 [#40](https://github.com/ghwls9896/CampusCommons/issues/40), 초안 [PR #41](https://github.com/ghwls9896/CampusCommons/pull/41).
- 최신 main `4b48b9c`에서 분리했다. 공유 파일 `backend/app.py`는 마피아 API 등록 작업을 마쳤다. 진행 중이던 #31·#33·#35·#37·#39와 수정 파일이 겹치지 않았다. 3D 포털은 기존 메인 씬을 사용하고 Player, 씬, Render 설정 파일은 기존 것을 사용한다.
- 방 참가, 채팅, 턴별 AI 대화, 밤 보호, 최종 지목을 포함한다. 참가자별 토큰과 서버 순번으로 방 대사를 공유한다. 방 상태는 단일 Render 워커의 메모리에 있다.
- Unity 6000.4.5f1에서 모의 로그인 후 실제 문을 통과하여 패널 입력 상태와 라운지 복귀를 확인했다. Unity Search 인덱싱의 편집기 예외와 기본 아바타 경고가 있었다. 두 참가자의 대사 동일성, 요청 단서 분리, 예산 및 장애 처리는 백엔드 테스트에서 모의 모델을 사용했다.
- 실제 GPU 배포, 새 Render API 배포 및 서로 다른 PC의 실제 Unity/GPU 테스트는 Modal 계정과 지출 한도 설정 확인 뒤 이어간다. [배포 안내](../mafia/DEPLOYMENT.md)
