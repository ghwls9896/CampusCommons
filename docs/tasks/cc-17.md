# CC-17 최신 맵과 아바타 통합 인계

- Issue #17, PR #18, 담당 ghwls9896, 작업 브랜치 `codex/cc-17-npc-sounds`.
- 사용자의 현재 Unity 씬과 탈출맵의 편집 가능한 여섯 배치 지점, 문 열기/닫기 소리 및 몬스터의 문 소리 감지, NPC 잠긴 경로 우회와 효과음을 통합합니다.
- GongBeak의 아바타 코드(PR #20)를 기반으로 Player에 연결했습니다. 외부 Sunbox 원본과 파생 프리팹은 배포하지 않으며 설치 전에는 기본 캐릭터가 동작합니다. 설치 및 심볼 설정은 `docs/AVATAR_SETUP.md`를 참고합니다.
- 공유 파일: 메인 씬, Player, `Packages/manifest.json`, `Packages/packages-lock.json`. 사용자는 아바타 Player 연결을 캐릭터 담당자와 조율했다고 확인했습니다. PR #20과 중복 통합하지 않도록 담당자와 순서 확인 필요. PR #10과 #4의 패키지 항목도 통합 시 확인 필요. 공유 파일 범위 표시는 승인이나 잠금이 아닙니다.
- 사용자 원본 프로젝트는 건드리지 않았으며 씬은 사용자 원본의 저장본에서 가져왔습니다. 편집 중 씬의 미저장 상태는 확인 범위에 포함되지 않습니다.
- Unity 6000.4.5f1 복사본: Sunbox 미설치 시 컴파일·기본 캐릭터, 로비 좌석·문 세 곳·방 입장/귀환·탈출 진입/복귀 및 계단 통행 통과. Sunbox 설치 및 심볼 활성 시 아바타 생성, UI 열기/닫기, 성별 변경, 1·3인칭 전환 통과.
- 기존 PR 검증에서 합성 격자의 NPC 경로 우회와 탈출 진행을 확인했습니다. 실제 전체 맵에서 모든 잠긴 문의 우회가 가능한지는 보장하지 않습니다. 소리 청감과 모든 해상도의 UI, 실제 다른 팀원 PC에서의 설치는 미검증입니다.
- 사람 리뷰 및 PR #20·#10·#4와 공통 파일 통합 순서 확인이 남아 있습니다. 최종 검토·통합 담당 HIGHCHOI; 자동 병합하지 않습니다.
