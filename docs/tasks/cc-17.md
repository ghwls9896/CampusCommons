# CC-17 탈출룸 NPC 소리와 동전 표시 인계

- Issue: https://github.com/ghwls9896/CampusCommons/issues/17
- 담당: ghwls9896. 브랜치: codex/cc-17-npc-sounds. 최종 커밋은 PR head 참조.
- 교수의 직접 합성한 허밍과 시설관리 직원의 공구 소리를 3D 거리별로 재생합니다. 큰 발소리는 사용하지 않고 7~12초 간격 및 가까운 NPC 간 중복 방지를 적용합니다.
- 동전 개수를 왼쪽 위의 짙은 패널로 옮기고, 음료 속도 증가 표시에도 배경을 추가합니다.
- Unity 6000.4.5f1 Play Mode 검사: 기존 로비 입장·문제·자판기 구매·교수 질문·문 잠금·탈출 통과. 별도 검사에서 각 NPC 오디오 클립, 거리/볼륨 및 가까운 NPC 소리 겹침 지연 확인.
- 소리의 실제 청감과 해상도별 HUD 시각 확인은 사람이 직접 확인해야 합니다. Unity SearchDatabase 에디터 초기화 오류가 테스트 로그에 별도로 있었으나 Play Mode 검사는 통과했습니다.
- 공유 씬, Player, GameStart, Packages/ProjectSettings 변경 없음. 원본 Unity 프로젝트의 기존 미커밋 변경 보존. 마지막 커밋과 CI 상태는 PR에서 확인하고 HIGHCHOI가 사람 리뷰·통합합니다.
