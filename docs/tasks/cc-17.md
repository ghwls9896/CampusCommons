# CC-17 탈출룸 NPC 소리와 동전 표시 인계

- Issue: https://github.com/ghwls9896/CampusCommons/issues/17
- 담당: ghwls9896. 브랜치: codex/cc-17-npc-sounds. 최종 커밋은 PR head 참조.
- 교수의 직접 합성한 허밍과 시설관리 직원의 공구 소리를 3D 거리별로 재생합니다. 큰 발소리는 사용하지 않고 5.5~9초 간격 및 가까운 NPC 간 중복 방지를 적용합니다.
- 동전 개수를 왼쪽 위의 짙은 패널로 옮기고, 음료 속도 증가 표시에도 배경을 추가합니다.
- Unity 6000.4.5f1 Play Mode 검사: 기존 로비 입장·문제·자판기 구매·교수 질문·문 잠금·탈출 통과. 별도 검사에서 각 NPC 오디오 클립, 거리/볼륨 및 가까운 NPC 소리 겹침 지연 확인.
- 소리의 실제 청감과 해상도별 HUD 시각 확인은 사람이 직접 확인해야 합니다. Unity SearchDatabase 에디터 초기화 오류가 테스트 로그에 별도로 있었으나 Play Mode 검사는 통과했습니다.
- 공유 씬, Player, GameStart, Packages/ProjectSettings 변경 없음. 원본 Unity 프로젝트의 기존 미커밋 변경 보존. 마지막 커밋과 CI 상태는 PR에서 확인하고 HIGHCHOI가 사람 리뷰·통합합니다.

## NPC 잠긴 경로 후속

- 교수와 시설관리 직원은 남은 경로의 문이 잠기면 같은 목적지의 우회로를 바로 계산하고, 불가능하면 도달 가능한 다른 순찰 목적지를 선택합니다. 잠금 해제 시 경로를 다시 이용할 수 있습니다. NPC는 순간이동하지 않습니다.
- Unity 6000.4.5f1 Play Mode `EscapeNpcLockedRouteVerification`: 합성 격자·문에서 두 NPC의 잠금 직후 우회·즉시 이동, 우회 불가능 시 대체 목적지, 문 해제, 소리 간격 5.5~9초 확인. 실제 맵 전체 문의 우회 가능성을 보장하는 검사는 아닙니다.
- `EscapeWorldIntegrationVerification` 통과. `EscapeWorldPatrolVerification`은 첫 실행에서 90 게임초 내 안전 공사벽 위치를 찾지 못해 실패했고 재실행에서 두 NPC 이동 및 안전 벽 설치가 통과했습니다. 무작위 배치의 장시간 안정성은 추가 검토가 필요합니다.
- 원본 Unity 프로젝트의 수정 전 스크립트를 별도 백업한 뒤 변경을 적용했습니다. 공유 씬, Player, 프리팹 및 패키지는 편집하지 않았습니다. 이 범위의 공유 파일 수정은 없습니다.
