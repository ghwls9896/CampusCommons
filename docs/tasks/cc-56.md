# CC-56 인계

- 탈출룸의 벽·바닥 경계 113개 구간을 마감하고 바깥 여섯 면에 빛 차단 메시를 배치했습니다. 마감 프리팹에는 이동을 막는 Collider를 추가하지 않았습니다. 학교 벽·천장이 양쪽에서 그림자를 받도록 정리하고 어두운 모드의 손전등 그림자 설정을 조정했습니다.
- 로비 가구 9종에는 기존 Poly Haven CC0 모델과 같은 에셋의 ARM 텍스처를 적용했습니다. Unity Standard 재질이 읽는 채널에 금속성·차폐·매끄러움을 옮겼습니다. 카페 카운터, 그라인더, 샹들리에, 문과 카펫에도 에셋에 맞는 표면 재질을 적용했습니다.
- Unity 6000.4.5f1에서 컴파일, 테스트 계정으로 쉬움 입장과 문 완전 개방, 어려움 입장과 손전등, 두 모드의 로비 복귀가 통과했습니다. 복도와 카페를 렌더링해 비교했습니다. 사진에 있던 바닥 빛줄기와 벽 하단을 확인했으며, 일부 천장 경계에는 밝은 선이 남는 시점이 있었습니다. 전체 동선 수동 플레이와 실제 네트워크는 이번 검사 범위 밖입니다.
- 공유 씬 `Assets/StudyImmersive/Scenes/GrandLibrary_Living.unity`에는 학교 마감 프리팹 인스턴스 하나를 추가했습니다. 씬 담당 ghwls9896의 로컬 Unity 저장분을 반영했으며, 열린 #33·#55에 같은 변경 경로가 없는 것을 확인했습니다. 수정 작업은 종료했고, 최종 커밋 및 CI 결과는 [PR #57](https://github.com/ghwls9896/CampusCommons/pull/57)에 연결합니다. HIGHCHOI 검토 후 Squash merge를 요청합니다.
