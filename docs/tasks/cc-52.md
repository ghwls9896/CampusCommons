# CC-52 계정 화면 인계

HIGHCHOI가 황혼의 대도서관 배경과 전체 화면 로그인·회원가입, 계정 인증과 프로필 조회에 연결한 2단계 입장 바를 구현했다. 로그인 아래에는 비밀번호 찾기를 중앙에 둔다. 이메일 인증은 가입 직후와 인증이 필요한 로그인에서 이어진다. 서버가 중복 오류를 반환하면 이메일을 유지한 채 로그인으로 안내한다. 가입 여부를 숨기는 응답에는 새 가입자와 기존 가입자 모두를 위한 안내를 표시한다.

Unity 6000.4.5f1의 계정 Play Mode 검사에서 중복 오류 2종, 미인증 로그인, 일반 가입 응답, 가입 인증, 프로필 지연, 입장, 세션 만료와 로그아웃을 로컬 인증 응답으로 확인했다. #51 실행 경로와 조합한 macOS ARM64 빌드에서 3024×1898 전체화면 로그인 배치를 확인했다. 별도의 macOS 검증본에서 700×670 가입 화면과 계정 인증·프로필 대기·재시도 화면을 렌더링했다. 실제 이메일 발송과 Windows 플레이어는 이번 검증에 포함하지 않았다.

공유 씬 및 서버 변경은 없다. 현재 구현 커밋은 PR #53의 마지막 기능 커밋이며 정확한 SHA는 PR에 기록한다. ghwls9896가 리뷰한 뒤 통합할 수 있다.
