# CC-52 계정 화면 인계

HIGHCHOI가 황혼의 대도서관 배경과 전체 화면 로그인·회원가입, 제출 버튼의 원형 로딩 애니메이션과 프로필 조회 단계의 입장 바를 구현했다. 로그인 아래에는 비밀번호 찾기를 중앙에 둔다. 가입 요청 후에는 메일 확인 화면에서 코드 입력과 로그인 복귀를 선택한다. 미인증 계정의 로그인은 코드 입력으로 이어진다. 서버가 중복 오류를 반환하면 이메일을 유지한 채 로그인으로 안내한다. 일반 가입 응답으로는 가입 여부를 구분하지 않는다. 복구 중 기존 비밀번호를 다시 입력하면 같은 화면에서 다른 비밀번호로 재시도할 수 있다. 로그아웃하면 안내 문구를 지우고 복귀 링크는 왼쪽 화살표를 표시한다.

Unity 6000.4.5f1의 계정 Play Mode 검사에서 중복 오류 2종, 미인증 로그인, 일반 가입 응답, 가입 인증, 프로필 지연, 입장, 세션 만료와 로그아웃을 로컬 인증 응답으로 확인했다. #51 실행 경로와 조합한 macOS ARM64 빌드에서 3024×1898 전체화면 로그인 배치를 확인했다. 별도의 macOS 검증본에서 700×670 가입 화면과 계정 인증·프로필 대기·재시도 화면을 렌더링했다. 후속 검사에서는 지연된 로그인과 가입 각각 두 프레임의 버튼 중앙 픽셀 변화를 비교하고, 가입 후 선택 화면과 왼쪽 화살표를 확인했다. 기존 비밀번호가 거부된 뒤 같은 복구 세션에서 다른 비밀번호로 성공하는 Play Mode 검사가 통과했다. 운영 서버 공개 설정에서 이메일 인증 활성 상태를 확인했다. 실제 이메일 발송과 Windows 플레이어는 이번 검증에 포함하지 않았다.

공유 씬 및 서버 변경은 없다. 현재 구현 커밋은 PR #53의 마지막 기능 커밋이며 정확한 SHA는 PR에 기록한다. ghwls9896가 리뷰한 뒤 통합할 수 있다.
