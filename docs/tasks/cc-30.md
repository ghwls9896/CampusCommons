# 교수 질문 공결증 사용

- 담당 ghwls9896 / 이슈 #30 / PR #31.
- 교수 질문·복습 중 공결증 슬롯을 명시한 사용 버튼을 표시하고 숫자열/숫자패드 1~3 및 질문 화면의 키 이벤트를 처리합니다. 해당 슬롯에 공결증이 있어야 사용되고, 사용하면 교수 질문이나 복습을 종료합니다.
- Unity 6000.4.5f1 Play Mode에서 시험용 로그인 응답으로 교수 질문과 복습, 각 슬롯의 일반 숫자열·숫자패드 키 처리 메서드, 다른/빈 슬롯과 실제 사용·해제를 검사했습니다 (`EXCUSE_NOTE_PASS`). 실제 장치 키 입력 및 버튼 클릭은 직접 확인이 남았습니다.
- 같은 버전의 통합 교수·아이템 및 탈출맵 회귀 검사 `CC15_WORLD_PASS`. Unity 시작 시 Search 인덱스 예외가 기록됐습니다.
- 원본 Unity 작업의 EscapeWorld.cs를 백업한 뒤 같은 수정으로 적용했습니다. 공유 씬·Player·패키지 설정은 수정하지 않았습니다. 원본 게임에서 직접 플레이 및 팀원 리뷰가 남았습니다.
