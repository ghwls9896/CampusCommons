# CC-64 인계

로컬 탈출룸에만 남았던 복도 조명, 교수·시설관리 직원·청소기의 복도 시작 위치, 인벤토리와 차단기 거리 위치, 자판기·동전·복도 물품 재질을 최신 main에 반영했습니다. 정숙 표지판 두 개를 기존 씬의 복도 중앙에 배치했습니다.

- Unity 6000.4.5f1 Play Mode에서 가짜 인증 응답을 사용해 쉬움·보통·어려움 각각 입장, 천장 조명 켜짐과 어려움 조명 꺼짐 및 어두운 모드 상태, 세 NPC 생성, 표지판 2개, 로비 복귀를 확인했습니다. 에디터 검색 색인 ArgumentOutOfRangeException은 출력됐고, 검사는 완료 표식과 종료 코드 0을 확인했습니다.
- 원래 씬에서 표지판 앞뒷면을 직접 렌더링해 글자 방향과 주변 조명에 반응하는 재질을 확인했습니다. 다인 접속, 실제 계정, 장시간 성능과 음성 청취는 검증하지 않았습니다.
- 공유 씬 담당 ghwls9896가 백업한 씬에서 표지판 두 개만 Unity 에디터로 최신 main 씬에 복사했습니다. 열린 #33·#59·#61·#63의 공유 씬 변경 여부를 확인했습니다. 씬 편집은 종료했습니다. 마지막 커밋과 CI 결과는 PR #65에서 확인할 수 있습니다.
- 소리 파일은 로컬과 main의 내용이 일치하여 기존 변경을 그대로 사용합니다.
