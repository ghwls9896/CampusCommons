# CC-68 인계

로컬 로비의 스타일숍 통합, 바리스타 모델, 독서등 6개, 계단 난간과 펜던트 연결 및 재질·반사 조정을 Unity 6000.4.5f1에서 최신 main 씬에 반영했습니다.

- 공유 씬 담당 ghwls9896의 기존 로컬 씬을 백업한 뒤 필요한 로비 오브젝트를 Unity 에디터에서 옮겼습니다. 씬 편집은 종료했습니다.
- Unity 6000.4.5f1에서 통합 씬을 열고 종업원 위치·방향·렌더러, 독서등 6개, 계단 충돌체 54개와 누락 스크립트를 확인했으며 화면을 렌더링했습니다.
- 테스트 인증 응답을 사용한 Play Mode에서 쉬움·보통·어려움 탈출룸 입장, NPC 생성, 조명, 표지판 및 로비 복귀가 통과했습니다. Unity SearchDatabase 예외와 웹캠 런타임 준비 DirectoryNotFoundException이 출력됐습니다.
- 스타일숍 구매·상호작용, 종업원 애니메이션, 실제 로그인·웹캠, 다인 접속, 조명 성능과 계단 직접 보행은 미검증입니다. 종업원은 정적 모델입니다. 모델의 얼굴 사진은 사용자가 제공한 이미지를 포함합니다.
- #61과 #59를 main에 반영했습니다. 최신 커밋 및 CI 결과와 다음 검토 단계는 PR #70에 기록합니다.
