# 웹캠과 공부 창을 함께 확인

1. QEV의 카메라 분석에 종이 공부와 컴퓨터 사용을 구분하는 내부 선택지를 추가합니다. Unity에는 결합한 다섯 상태와 관측 여부를 전달합니다.
2. 세션에서 직접 고른 창이 활성일 때 앱과 제목을 평가하고, 애매한 경우에 해당 창을 메모리로 읽습니다. 창이나 제목이 바뀌면 이전 관측을 폐기합니다.
3. Unity의 착석 화면에서 창 선택과 해제를 제공하고 화면 근거가 없는 구간의 집계를 보류합니다. 기존 공부 기록과 동기화 API를 사용합니다.
4. 플랫폼별 캡처 구성 요소를 동봉 런타임에 넣고, 가짜 화면 결과와 실제 QEV로 동작을 검사합니다.

## 사용과 인계

로비에서 좌석에 앉고 **시작**을 누릅니다. 컴퓨터로 공부할 때는 왼쪽 아래 **공부 창 선택**에서 창을 고르고 해당 창으로 이동합니다. 종이 공부는 카메라 근거로 집계합니다. 컴퓨터 사용으로 판정했을 때는 선택한 창의 공부 근거가 있어야 집계합니다. 같은 창에서 탭 제목이 바뀌거나 다른 창으로 이동하면 이전 화면 판정은 만료됩니다.

화면 캡처와 판정은 기기 안에서 진행하며 영상과 창 정보는 저장하지 않습니다. 기존 공부 기록 API에는 확정된 행동별 시간 구간이 전달됩니다. 로컬 Mac 확인용 앱에는 기존 설치에 있던 Sunbox 아바타와 동봉 QEV 런타임을 사용합니다.

| 검증 | 결과 |
|---|---|
| Python·브라우저·배포 테스트 | 웹캠 테스트 24개 통과 및 선택 테스트 2개 건너뜀, 브라우저 10개·배포 5개 통과 |
| Unity 6000.4.5f1 | 로비 입장, 좌석 타이머, MY 기록, 메뉴 입력 우선순위와 로그아웃 통과. 공부 기록 검사 13개 통과 |
| Apple Silicon | 실제 창 캡처와 OCR, 합성 강의 화면의 실제 QEV 판정, 이동한 패키지의 오프라인 추론 및 Mac 앱 런타임 준비 확인 |
| Windows x64 | 동봉 Windows Graphics Capture 패키지의 HWND API 확인. Windows 기기 실행 검증은 남아 있음 |
