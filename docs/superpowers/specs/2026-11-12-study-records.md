# 백그라운드 공부 시간과 계정 기록

사용자가 2026-11-12 대화에서 승인한 설계: 다른 창에서도 측정 지속, 최근 약 3초 점수에 최신 가중치, 공부 진입 3초/비공부 2초/자는중 표시 8초. 화면은 기존 다섯 행동 범주와 이번 공부/오늘 누적. 영상 저장·전송 없음. 모델은 QEV-0.8B fast, 1초 목표를 유지한다.

연속 N회와 시간 가중 점수 평활화를 비교했고 사용자는 후자를 승인했다. 실제 촬영 시각 기준 시간 계산, UI 상태와 공부/비공부 시간을 분리한다. 후보 전환 구간은 보류 후 확정/되돌림 처리한다. 첫 유효 촬영 이전, 절전/3초 초과 결과 공백, 권한 오류는 누적하지 않는다. 점수/시간 임계값은 초기값이며 실제 정확도 보장이 아니다.

계정별 세션과 불변 구간을 저장한다. 일별 기준은 한국시간(UTC+9), 내부 UTC epoch milliseconds. 30초마다 및 종료 후 동기화, 작은 로컬 outbox를 원자적으로 보관하고 실패 시 재시도. 계정 ID는 API가 검증한 Auth ID만 사용. 세션ID+구간번호로 idempotency, 서버는 구간 범위/순서/겹침을 검사. 본인 기록만 RLS SELECT 가능, 쓰기는 서버 RPC만. 보상/레벨 정책은 그대로 비활성.

소스 기반은 로컬 통합 c3ab5e0. 기존 linked worktree에서 codex/study-records로 분기했으며 Sunbox 미추적 에셋은 보존한다. main에 아직 없는 기존 기능은 선행 통합 PR의 변경으로 분리한다. 사용자 승인은 현재 구현 요청이며 추가 설계 승인 대기는 하지 않는다.
