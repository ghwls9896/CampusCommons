## Earlier spike plan

> Execute inline with superpowers:executing-plans, test-driven-development and one independent final review.

**Goal:** Verify local small-VLM execution conditions before integrating webcam inference into Unity.
**Architecture:** Portable pinned llama.cpp + local model/image files; loopback requests from a Python stdlib benchmark; validated activity labels and raw measured evidence.
**Tech Stack:** Python 3, llama.cpp GGUF/mmproj, macOS Apple M4 32 GB; Windows remains a required follow-up platform.
**Spec:** ../specs/2026-11-09-local-vlm-design.md

## Global Constraints
- No cloud inference, personal camera capture, user video storage or DB.
- No Unity scenes/common scripts/packages changed during this phase.
- Invalid model output is unknown, never automatically study/away.
- Record model/runtime versions and public image provenance; do not commit downloaded images or binaries.

## Review Focus
- Malformed or truncated labels must not become valid study time.
- Remote endpoints and redirects must not receive image contents.
- HTTP/network errors must remain failures, not successful samples.
- Repeated images and small hand-picked examples must not be reported as real-world accuracy.
- Keep process RSS, model file size and total GPU/system memory distinct.
