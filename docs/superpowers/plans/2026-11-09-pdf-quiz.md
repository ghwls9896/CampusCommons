# PDF Quiz Implementation Plan

> Execute inline with superpowers:executing-plans; use test-driven-development and one independent final review.

**Goal:** A single-player PDF quiz room with three difficulty levels and answer explanations.
**Architecture:** Unity QuizRoom -> bounded FastAPI PDF endpoint -> Gemini structured output; no client LLM key.
**Tech Stack:** Unity C#/IMGUI/UnityWebRequest; Python/FastAPI/httpx/pypdf; Render Free.
**Spec:** ../specs/2026-11-09-pdf-quiz-design.md

## Global Constraints
- Preserve existing scenes and Unity 6000.4.5f1 project version.
- Windows/macOS; Korean, four options, exactly levels 1/2/3; max 10 MiB/80 pages.
- Free plan configuration, no automatic paid fallback, no durable uploaded files.

## Review Focus
- Leaving during a request must cancel it and cannot show stale questions on re-entry.
- Invalid PDF/model JSON, empty material and nonexistent page references must fail clearly.
- Render cold start and Gemini quota errors must have bounded waiting and explicit retry.
- Quiz UI must not trap the cursor or interfere with existing exit confirmation and other rooms.
- Team code/key must not be embedded in git; daily limits are process-local demo controls.
