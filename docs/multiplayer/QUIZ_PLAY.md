# 두 사람이 퀴즈룸에서 학습하기

1. 두 창에서 서로 다른 계정으로 로그인한다. 같은 도서관 로비와 퀴즈 교실에서는 상대의 이동과 머리 위 닉네임·레벨이 보인다.
2. 교실 앞 칠판에서 규칙을 확인한다. 의자 가까이에서 **E 앉기**가 뜨면 E를 누른다. 첫 참가자는 상대를 기다리고, 두 번째 참가자가 다른 의자에 앉으면 두 사람 모두 자료를 선택할 수 있다.
3. 칠판의 **PDF 선택하기**를 누르면 macOS 또는 Windows의 파일 선택 창이 열린다. 폴더에서 자기 PDF를 선택하고, 필요한 경우 페이지 범위를 지정한 뒤 **이 PDF로 참가**를 누른다. 파일은 최대 10 MiB, 선택 범위는 최대 1,000페이지다.
4. 두 세트가 준비되면 동시에 시작한다. 같은 칠판을 보더라도 각 참가자에게는 자기 PDF의 문항이 표시된다. **공통 난이도 Lv.숫자**는 두 계정 레벨 평균을 반올림한 출제 기준이다. 객관식은 보기 선택 후 10초 안에, 단답형과 서술형은 각각 15초·20초 안에 입력하고 **답 제출**을 누른다. 시간이 끝나면 서버에 저장된 마지막 답을 채점한다.
5. 둘 다 마치면 칠판에서 두 사람의 총점(30점), 정답률과 풀이 시간을 비교한다. 아래로 스크롤하면 자기 답·모범 답안·해설·근거 페이지가 보인다. **일어나기**로 교실 시점으로 돌아온다.

## Mac에서 두 창 열기

교실 시연 폴더에서 **2인 퀴즈 두 창 열기.command**를 연다. A 또는 B를 닫았다면 같은 파일을 다시 열면 닫힌 창만 실행된다. 두 창은 같은 Render 서비스에 직접 연결한다. 좌석·타이머·출제·채점은 서버가 담당한다. [배포한 서버 PR](https://github.com/ghwls9896/CampusCommons/pull/50)

로비와 교실은 같은 8명 연결 한도를 공유한다. 클라이언트는 기존 서버가 보내는 월드 좌표에서 현재 공간에 있는 캐릭터를 골라 표시한다. PDF·문제·답안은 개인 좌석 API를 통해서만 주고받는다.
