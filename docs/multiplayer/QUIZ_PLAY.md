# 두 사람이 퀴즈룸에서 학습하기

1. 두 창에서 서로 다른 계정으로 로그인한다. 같은 도서관 로비와 퀴즈 교실에서는 상대의 이동과 머리 위 닉네임·레벨이 보인다.
2. 교실 앞 칠판에서 규칙을 확인한다. 의자 가까이에서 **E 앉기**가 뜨면 E를 누른다. 혼자 착석하면 화면 아래에 **상대 참가자 대기 중 · 1/2**가 표시되고 벽면 칠판에는 규칙이 계속 보인다. 우클릭을 누른 채 둘러보거나 E를 눌러 일어날 수 있다. 두 번째 참가자가 다른 의자에 앉으면 두 사람 모두 칠판에서 자료를 선택할 수 있다.
3. 칠판의 **PDF 선택하기**를 누르면 macOS 또는 Windows의 파일 선택 창이 열린다. 폴더에서 자기 PDF를 선택하고, 필요한 경우 페이지 범위를 지정한 뒤 **이 PDF로 참가**를 누른다. 파일은 최대 10 MiB, 선택 범위는 최대 1,000페이지다.
4. 두 세트가 준비되면 동시에 시작한다. 각 참가자에게는 자기 PDF의 문항이 표시된다. **공통 난이도 Lv.숫자**는 두 계정 레벨 평균을 반올림한 출제 기준이다. 제한 시간과 배점은 객관식 **15초·2점**, 단답형 **30초·3점**, 주관식 **60초·5점**이다. **답 제출**을 누르면 다음 단계로 넘어가고, 시간이 끝나면 서버에 저장된 마지막 답을 채점한다.
5. 둘 다 마치면 칠판에서 총점(10점)과 문제별 정확도·풀이 시간·경기 XP를 비교할 수 있다. 객관식은 정오로, 단답형·주관식은 AI가 채점 기준을 얼마나 충족했는지 판단한다. 경기 XP는 결과 화면에 표시된다. 아래로 스크롤하면 자기 답·모범 답안·해설·근거 페이지가 보인다. **일어나기**로 교실 시점으로 돌아온다.

## Mac에서 두 창 열기

운영 Render에 연결하는 교실 시연 폴더에서는 **2인 퀴즈 두 창 열기.command**를 연다. A 또는 B를 닫았다면 같은 파일을 다시 열면 닫힌 창이 실행된다. 작업 중인 서버 코드를 검증하는 로컬 시연에서는 두 창이 Mac의 같은 서버에 연결되고 출제·채점은 Render에 요청한다.

로비와 교실은 같은 8명 연결 한도를 공유한다. 퀴즈 교실 입구는 두 좌석이 모두 차 있어도 통과할 수 있다. 세 번째 계정이 이미 찬 의자에 앉으려 하면 서버가 거절하고 캐릭터가 다시 일어난다. 진행 중인 경기는 그대로 이어지고, PDF·문제·답안은 각 참가자의 좌석 API를 통해서만 전달된다.

탈출룸과 마피아룸은 플레이어마다 자기 Unity 실행에서 따로 열린다. A가 탈출 중일 때 B도 같은 문으로 들어갈 수 있으며 B는 자기 난이도 선택부터 진행한다. 두 사람은 서로 보이지 않고 진행 상황도 공유하지 않는다. 마피아룸은 공간 입장과 로비 복귀까지 제공한다.
