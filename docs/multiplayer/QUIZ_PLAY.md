# 두 사람이 퀴즈룸에서 학습하기

1. 서로 다른 계정으로 같은 서버에 로그인한다. 도서관에서는 상대 머리 위에 자기 캐릭터와 같은 형식의 닉네임과 레벨이 뜬다.
2. 각자 퀴즈룸에 들어가 서로 다른 의자에 다가가 **E**를 누른다. 먼저 앉은 사람은 대기 화면을 본다. 같은 의자를 선택하면 이미 사용 중이라는 안내가 나오므로 다른 자리에 앉는다.
3. 두 자리가 차면 각자 **PDF 선택하기**에서 자기 학습 자료를 고르고 **이 PDF로 참가**를 누른다. 원하는 페이지 범위를 지정할 수 있다. 파일은 최대 10 MiB, 선택 범위는 최대 1,000페이지다.
4. 두 사람의 계정 레벨 평균을 반올림한 공통 기준으로 AI가 PDF마다 한 세트씩 출제한다. 두 세트가 준비되면 동시에 시작한다. 객관식 10초, 단답형 15초, 서술형 20초다. 답을 제출하면 다음 단계로 넘어가고, 시간이 끝나면 서버에 저장된 마지막 답을 채점한다.
5. 두 사람이 마치면 결과 화면에서 총점(30점), 단계별 점수·시간, 정답률을 비교한다. 정답률은 3문제 중 만점 문항의 비율이다. 부분점수는 총점에 포함되고, 개인 답안·해설·근거 페이지도 다시 볼 수 있다. 좌석에서 일어나면 다음 경기에 참가할 수 있다.

## 서버와 Mac 시연

일반 데스크톱 빌드는 계정 로그인으로 기존 Render 서비스의 좌석을 사용한다. 서버 PR #50이 배포된 후 이용할 수 있다. 계정용 공개 설정은 기존 AccountConnection.json을 사용한다. Gemini API 키는 서버에서 관리한다. [서버 PR #50](https://github.com/ghwls9896/CampusCommons/pull/50)

Mac 두 창 퀴즈 실행본은 127.0.0.1의 18648 포트에 같은 서버를 띄운다. 이전 로비 시연본과 포트가 다르다. Mac에서 직접 출제·채점하려면 퀴즈 서버를 여는 터미널에 무료 프로젝트의 Gemini 키를 입력하거나 GEMINI_API_KEY를 환경변수로 설정한다. 게임 클라이언트에는 키를 넣지 않는다. 키를 생략하면 실제 로그인·이름표·좌석 대기를 확인할 수 있다.

## 다시 확인할 때

개인 PDF가 다른 플레이어에게 보이지 않는지, 서로 다른 레벨의 두 계정에서 같은 목표 레벨이 표시되는지 확인한다. 파일 등록 중 퇴실하면 남은 플레이어가 다시 대기 상태로 돌아가야 한다. 이미 결과를 본 상대가 먼저 나가도 남은 플레이어는 자기 결과를 확인할 수 있다.
