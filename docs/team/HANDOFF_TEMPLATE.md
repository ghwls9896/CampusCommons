# CC-번호 인수인계

- Issue / PR:
- 사람 담당 / 브랜치 / 마지막 커밋:
- 지금 상태: 작업 중 / 리뷰 대기 / 막힘 / 통합 완료 (실제 상태만)
- 완료한 행동과 사용자가 확인할 결과:
- 남은 일 / 다음 에이전트의 첫 행동:
- 수정한 경로 / 공유 파일 조율 Issue와 현재 작업자:
- API·필드·프리팹 계약 변경과 먼저 합칠 PR:
- 실행한 검사: 명령, 버전, 결과
- 실행하지 못한 검사 / 이유:
- 외부 설정 필요: 변수 이름만, 비밀값 금지
- 작업 종료/인계에 동의한 사람과 Issue 기록:
