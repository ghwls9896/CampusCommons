# 학교 까마귀 몬스터

## 실행

Unity 6000.4.5f1에서 `CampusCommons` 프로젝트의 `Assets/StudyImmersive/Scenes/GrandLibrary_Living.unity`를 열고 Play를 누릅니다. 라운지의 ESCAPE ROOM 포탈에 들어가 난이도를 고르면 학교 게임이 시작됩니다. Unity가 이미 실행 중이라면 Play를 끝내고 스크립트 컴파일이 완료된 후 다시 실행하세요.

## 몬스터 행동

까마귀는 처음 8초 동안 기다린 뒤 순찰하며, 가까운 문을 열고 방 안쪽까지 들어가 수색합니다. 최대 150m까지 모든 방향의 학생을 감지하지만 벽이나 닫힌 문 너머는 볼 수 없습니다. 학생을 놓치면 마지막으로 본 곳을 수색하다 다시 순찰합니다. 추격과 수색 중 문을 열고 충분히 회전할 때까지 기다린 뒤, 열린 문짝을 피해 경로를 다시 계산합니다.

마지막 문제지를 풀면 화면 전체가 붉어지고 시점이 흔들립니다. 까마귀는 벽 너머의 학생 위치도 알게 되고, 이전 추격 속도의 2.2배로 쫓아옵니다. 벽을 통과하지는 않으며 학교 경로와 문을 이용합니다. 퀴즈 풀이와 나가기 확인 중에는 몬스터도 멈춥니다.

학교에 있는 밝은 `EXIT` 엘리베이터 세 곳 중 아무 곳이나 클릭하거나 E를 눌러 탈출하세요. 문제지를 다 모으기 전에는 안내만 표시됩니다. 목적지 표시와 거리는 화면에 나오지 않습니다.

잡히면 카메라가 까마귀 쪽으로 끌려가고, 별도 얼굴 이미지와 효과음이 나타난 뒤 결과 화면으로 전환됩니다. ESC로 라운지에 돌아갈 수 있습니다. 효과음은 직접 만든 임시 소리입니다.

학교는 기존 격자 경로 탐색을 확장했으므로 NavMesh 패키지나 별도 베이크가 필요 없습니다. 학교 지형을 크게 수정하면 기존 격자도 다시 생성해야 합니다. 파란 벽 위 장식은 학교 벽과 문 위치에 맞춰 생성한 충돌 없는 메시이며 Play 중 표시됩니다. 벽 구조를 수정했다면 학교 씬을 연 뒤 `Campus → Rebuild school upper blue trim` 메뉴로 장식을 다시 만들 수 있습니다.

## 조절과 리소스

Hierarchy의 까마귀 `Monster` 컴포넌트에서 `Sight Distance`, `Search Seconds`, `Room Search Range`, `Room Search Interval`, `Final Speed Multiplier`, `Sound Range` 등을 조절할 수 있습니다. `EscapeGame` 컴포넌트에서 갑작스러운 등장 연출과 `Panic Tint Opacity`, `Panic Shake Strength`를 조절할 수 있습니다. 소리와 이미지는 `Assets/LibraryCharacter/Resources`에 있습니다.

추격 캐릭터는 단일 이미지라 이동 거리에 맞춘 가벼운 튀어 오름과 크기 변화로 움직임을 표현합니다. 잡혔을 때의 이미지는 기존 까마귀를 직접 편집한 별도 그림입니다. 다리가 실제로 움직이려면 걷기·달리기 스프라이트 시트를 추가해야 합니다.
