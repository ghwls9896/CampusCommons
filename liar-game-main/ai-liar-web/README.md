# PDF 기반 AI 라이어 게임 — 독립 웹 검증 프로토타입

이 폴더는 업로드된 `liar-game-main` 원본 코드를 보존하면서 별도로 실험할 수 있도록 추가한 웹 개발용 프로토타입입니다. **원본의 Socket.IO/Redis 룸과 아직 연동되지 않습니다.**

## 실행

```bash
cd ai-liar-web
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload --port 8000
```

웹브라우저: http://localhost:8000

1. `버블 정렬 예제로 시작`을 눌러 데이터 없이 테스트하거나, 텍스트가 들어 있는 PDF를 업로드합니다.
2. 자동 후보에서 PDF에 실제로 등장한 개념을 선택하거나 직접 입력합니다.
3. 게임 시작 → AI 발언 진행(6 NPC × 2회) → 비전공자 선택 → 정답·PDF 근거 확인.

## LLM 연결 (선택 사항)

기본 동작은 **규칙 기반 시뮬레이션**이며 AI 모델 추론이 아닙니다. 실험용 문장과 PDF의 일부를 대사로 출력합니다. 실제 NPC 대화 생성에는 OpenAI-compatible Chat Completions API가 필요합니다. 서버 실행 전에 아래를 설정하세요(예시는 값이 아닌 변수명입니다).

```bash
export LIAR_LLM_API_URL='https://YOUR-LLM-ENDPOINT/v1/chat/completions'
export LIAR_LLM_MODEL='YOUR_MODEL_NAME'
export LIAR_LLM_API_KEY='YOUR_API_KEY'
```

세 변수가 설정되면 역할별 프롬프트로 LLM을 호출합니다. **비전공자 프롬프트에는 제시어·PDF 근거를 포함하지 않고 공개 토론 내용만 전달합니다.** 단, 사전학습 모델의 내재 지식은 차단할 수 없으며 프롬프트 준수도 보장되지 않습니다. 실제 서비스 전 내용 검증, 비전공자 발언 필터링, 정확도 검증, 길이·횟수 제한, 비용 관리가 필요합니다.

## 구현 범위 / 제한

- 구현: PDF 텍스트 추출(PyMuPDF), 후보 단어 추출(휴리스틱), 개념 근거 탐색, 비전공자 무작위 배정, NPC 12회 발언, 사용자 투표, 정답 공개 및 근거 페이지, 데모 경험치.
- 미구현: 스캔 PDF OCR, RAG/FAISS, NPC 자체 투표, 퀴즈 품질 검증, 영속 DB, 계정, Unity 연동, 원본 Socket.IO 룸 연동, 실제 경험치 지급.
- 로컬 개발 테스트 용도: 세션은 프로세스 메모리에 저장됩니다. 동시 접근·세션 만료·보안 강화가 필요한 운영 환경용이 아닙니다.
- PDF는 앱 프로세스 메모리에만 올려서 분석하며 임의의 원격 LLM 호출을 활성화하면 **근거 텍스트 일부**가 지정한 외부 API로 전송됩니다. 개인 정보나 비공개 자료로 LLM 실험 전 제공자 정책을 확인하세요.
- 업로드 PDF 40MB/100페이지 제한. 기본 로컬 모드에서 외부 업로드 없음.
- 오픈소스 재배포 조건: 업로드된 원본 압축파일에는 `LICENSE` 파일이 보이지 않습니다. 원저작자의 배포 조건을 확인하고 공개/재배포하세요.
