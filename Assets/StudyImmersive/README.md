# 개선된 도서관과 탈출방

Unity에서 `Assets/StudyImmersive/Scenes/GrandLibrary_Living.unity`를 열고 Play를 누르세요. 메뉴의 `Campus > Open living library and set as startup`을 선택하면 개선된 씬을 열고 빌드 첫 씬으로 지정합니다. 기존 `GrandLibrary.unity`와 이전 개선 씬은 보존했습니다.

## 공간

- 공부용 테이블 6개와 의자 24개를 배치했습니다. 책상과 의자 모델의 실제 높이와 앉는 위치를 맞추고, 마피아 테이블을 낮추어 의자와 가깝게 배치했습니다.
- 라운지에 나무와 화단을 더하고 사용자가 보유한 `Unity URP Terrain Terrain Sample Project` 패키지의 풀·양치식물 모델을 현재 렌더러에 맞게 적용했습니다.
- 라운지와 마피아방, 퀴즈방에 식물·책·조명·책장 모델을 배치하고 러그의 재질을 개선했습니다.
- 사용자의 `8K Skybox Pack Free` 중 `sky-1`을 사용했습니다. 플레이 중 마우스 오른쪽 버튼을 누르고 위를 보면 천창 너머 하늘을 볼 수 있습니다.

## 탈출방

라운지의 `ESCAPE ROOM` 포탈에 들어가면 모드를 선택합니다. 선택하면 제공된 학교 모델 안에서 1인칭 시점으로 시작합니다.

| 모드 | 현재 목표 |
|---|---|
| 쉬움 | 노트 3개 수집 |
| 보통 | 노트 5개 수집 |
| 어려움 | 노트 7개 수집 |
| 타임어택 | 3분 안에 노트 5개 수집 |

`WASD`로 이동하고 마우스로 시점을 돌리며, 노트 가까이에서 `E`를 누르면 수집합니다. 언제든 `Esc`를 누르면 라운지로 돌아오며 다시 3인칭 시점이 됩니다. 모드 선택 화면에서도 `Esc`로 취소할 수 있습니다. 학교 내부의 기존 귀환 포탈은 이 씬에서 숨겨져 있습니다.

현재 난이도 차이는 노트 수와 시간제한입니다. 제공된 학교 폴더에는 게임 코드와 발디 추격 AI가 없었으므로 해당 기능은 아직 포함되지 않았습니다. 멀티플레이와 퀴즈·마피아 규칙도 별도 작업입니다.

## 에셋과 편집

`Assets/StudyImmersive/Realism/sources.json` 및 `RealismExtra/sources.json`에 Poly Haven 모델의 출처가 기록되어 있습니다. 모델과 러그 재질은 CC0입니다. 스카이박스와 풀·양치식물 모델은 사용자가 보유한 Unity Asset Store 패키지에서 가져온 별도 에셋입니다.

Unity 에디터에서 탈출방을 빠르게 시험하려면 Play를 누른 다음 `Campus > Testing > Visit escape portal in Play mode`를 선택할 수 있습니다.

탈출방 모드와 조작은 `Scripts/EscapeModeFlow.cs`에 있으며, 인스펙터에서 제한 시간과 노트 위치를 변경할 수 있습니다. 노트 위치는 학교의 이동 가능한 영역을 검사해 배치했습니다. 학교 구조를 크게 바꾸면 위치도 함께 조정하세요.
